Chaque embranchement d'une automatisation est une décision : quelle équipe reçoit ce lead, quelle urgence pour ce ticket, quels sujets aborde ce message. Branch Pilot transforme chacune en un **endpoint de décision** que vous définissez sans code, testez avec de vrais payloads et appelez depuis votre workflow.

## Ce que vous recevez

Une réponse typée, jamais du texte libre :

```json
{
  "status": "ok",
  "choice": "sales",
  "probabilities": { "sales": 0.87, "support": 0.09, "spam": 0.04 },
  "confidence": 0.87,
  "engine": "jev",
  "latency_ms": 212
}
```

- Les décisions **route** choisissent une option parmi 255 au plus.
- Les décisions **score** renvoient un score de 0 à 100 sur des niveaux ordonnés.
- Les décisions **classify** renvoient toutes les étiquettes dont la probabilité atteint leur seuil.

## Comment ça marche

Branch Pilot repose sur **Jev**, un modèle System One de TypeSafe AI. Contrairement à un modèle de langage, Jev ne génère pas de texte : il évalue vos options en parallèle et renvoie des probabilités calibrées. Il ne peut pas produire une réponse mal formée. Quand Jev est indisponible, Branch Pilot bascule sur Mistral avec le même schéma typé, et la réponse indique quel moteur a répondu.

Avant tout appel au modèle, les données personnelles de votre payload sont remplacées par des jetons neutres. Seul le payload pseudonymisé est envoyé aux moteurs et conservé dans votre historique. [Comment fonctionne la pseudonymisation](/fr/concepts/pseudonymization).
